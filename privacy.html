issue-upload 개인정보처리방침

시행일: 2026년 11월 5일

1. 이 앱은 무엇인가요

issue-upload는 채널 운영자 한 사람이 자기 유튜브 채널(이거핫하다는데?, 윤현빈 블로그)에 동영상을 올리고 채널 지표를 확인하려고 만든 개인용 도구입니다. 다른 사용자에게 서비스하지 않습니다.

2. 어떤 정보를 쓰나요

  • 운영자가 Google 로그인으로 허락한 범위 안에서 YouTube Data API와 YouTube Analytics API를 사용합니다.
  • 쓰는 정보: 운영자 채널의 동영상 목록, 조회수·좋아요·댓글 수, 시청 지표(시청 시간, 유입 경로, 시청자 연령·성별 비율 같은 합계 통계), 운영자가 올리는 동영상과 제목·설명.
  • 시청자 개인을 식별하는 정보는 받지 않고 저장하지 않습니다. 댓글은 내용 요약에만 쓰고 작성자 이름은 저장하지 않습니다.

3. 어디에 보관하나요

로그인 정보(인증 토큰)는 운영자의 개인 컴퓨터에만 보관하며 외부로 보내지 않습니다. 채널 지표 합계는 이 사이트의 지표 보드에 표시됩니다.

4. 제3자 제공

정보를 판매하거나 제3자에게 제공하지 않습니다. 이 앱의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. YouTube API 서비스 이용은 YouTube 서비스 약관과 Google 개인정보처리방침을 따릅니다.

5. 접근 권한 철회

Google 계정의 서드파티 앱 액세스에서 언제든지 이 앱의 권한을 해제할 수 있습니다. 해제하면 컴퓨터에 보관된 토큰은 더 이상 쓸 수 없습니다.
